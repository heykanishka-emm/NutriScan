# HealthGrade Prototype

A browser-based prototype for an app that scans packaged-food ingredient labels and assigns an A–F health grade.

## Run in VS Code

1. Extract/open this folder in VS Code.
2. Install the **Live Server** extension.
3. Right-click `index.html`.
4. Select **Open with Live Server**.
5. Allow camera permission when the browser asks.

You can also use Upload Image or paste an ingredient list manually.

## Important

This is a prototype heuristic, not a scientifically validated nutrition score. The scoring rules are intentionally simple and live in `app.js`.

For a production app, replace the heuristic with a validated scoring system and a proper ingredient/nutrition database.
